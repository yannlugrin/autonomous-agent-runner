# This installation's own secret shapes. One extended regular expression per
# line, with a note:
#
#     <regex>   # what it catches, and why it is anchored that way
#
# Blank lines and lines beginning with `#` are ignored, and everything from the
# first `#` on a rule line is the note.
#
# WHY THIS FILE EXISTS. The generic token shapes — PEM bodies, `ghp_`,
# `github_pat_`, `sk-ant-`, `AKIA` — stay in the code, because they are true of
# every installation. What is not is the shape of a secret this agent holds
# because of what it does: a forum's key format, a feed token, a webhook URL.
# Those are yours, so they live here, in a file that is not committed.
#
# TWO READERS, ONE FILE. `host/archive/scan.sh` appends these to the pattern
# floor `just collect` runs over every transcript, from this file in the
# checkout; `image/bash-guard.py` appends them to what it reads a commit and a
# push for, from the copy baked into the image. An absent file adds nothing to
# either.
#
# THE DIALECT. The line is handed to `grep -E` and to Python's `re` unchanged,
# so write only what both understand: no POSIX classes (`[[:space:]]` is a set
# of the letters in "space" to Python, and it matches something else in
# silence), and no lookahead. In a transcript a JSON string cannot hold a real
# newline, so anything armoured arrives on one line where both can see it whole.
#
# A SHAPE THAT FIRES ON ORDINARY PROSE IS ONE THAT GETS SWITCHED OFF, and then
# it is absent on the day it mattered. Anchor on the thing that only the secret
# has — a prefix, a parameter, a path — and give the value a length floor. Every
# rule below is written that way, and each note says on what.
#
# THE NOTE IS WHAT A REFUSAL NAMES — the guard says "this commit carries <note>"
# — so keep it to a name and a clause. The reasoning belongs in this header, or
# in docs/.
#
# A LINE THAT DOES NOT COMPILE refuses commits until it is fixed, naming the
# line: the alternative is a shape silently dropped, which is a check that reads
# as installed and compares less than it says.
#
# `just setup` copies this file to `image/config/secret-shapes.txt`, which is
# untracked. Editing that file is a boundary change under rule 3 of CLAUDE.md.
# see docs/boundary.md#the-shapes-and-the-rules-that-fire-on-prose

#1f916_sk_[A-Za-z0-9]{16,}   # a 1f916 forum key — `_sk_` and not the bare prefix, which is a handle and prose
#feed=[A-Za-z0-9_-]{16,}   # a Reddit feed token — anchored on the parameter, the value having no shape at all
#https://discord(app)?[.]com/api/webhooks/[0-9]+/[A-Za-z0-9_-]{40,}   # a Discord webhook URL — the URL is the secret, on the legacy host too
